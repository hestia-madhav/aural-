# EPP — English Proficiency Program

An A2Z Antifragility Foundation initiative to improve English speaking ability among children in rural Karnataka.

## Program Tools

1. **Aural Device** — Audio playback device for listen-and-repeat practice
2. **Bilingual Storybook** — "Kaadina Shaale" — physical book with English text and Kannada transliteration
3. **Digital Storybook** — Web version of the same story with integrated audio
